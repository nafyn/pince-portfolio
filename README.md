# pince portfolio — GitHub Pages package

This folder contains the finalized vertical portfolio and all of its local assets. It is a static website: no build step, package installation, or framework is required.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **the contents of this folder** to the repository root, keeping `cover`, `posters`, and `reports` as folders.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)`, then save.

The entry page is `index.html`. The `.nojekyll` file tells GitHub Pages to serve the static files directly.
